Hey! I'm Jake De Vera, a software and web developer based in the Philippines, building web applications from concept to deployment.

I work across the full stack — from clean, responsive interfaces to reliable backend systems — mostly on CakePHP and AngularJS codebases for local government units and small businesses. I also build and customize WordPress websites for clients who need a fast, easy-to-manage site.

My focus is practical software: systems that compute, track and report accurately, like payroll logs, tax applications and legislative records.
